# 🎪 Fun-Seum Entrance

An interactive, minimalistic bold entrance design for a fun museum website featuring an animated double door.

## ✨ Features

- **Animated Double Door**: Click to open with smooth 3D rotation animation
- **Minimalistic Bold Design**: Clean lines and toned colors with standout door elements
- **Architectural Arches**: Layered circular arches creating depth
- **Zoom-in Transition**: Smooth camera zoom effect when entering
- **Responsive Design**: Works beautifully on desktop and mobile devices
- **Interactive Platform**: Stepped platform base for visual interest
- **Keyboard Support**: Press spacebar to open doors

## 🎨 Design Elements

- **Color Palette**: Toned beige, taupe, and teal-green
- **Door Color**: Bold teal-green (#4a7a6a) that stands out against soft background
- **Arches**: Concentric circles with subtle opacity layers
- **Typography**: Bold uppercase letters with refined spacing

## 🚀 How to Use

1. **Click on either door** to trigger the opening animation
2. **Watch the zoom effect** as you enter the main content
3. **Press the back button** to return to the entrance
4. **Or press spacebar** on desktop to open doors

## 📁 Files

- `index.html` - Main structure
- `styles.css` - All styling and animations
- `script.js` - Interactive functionality

## 💡 Customization

You can easily customize:

- **Colors**: Edit the color values in `styles.css` (look for hex colors like #4a7a6a)
- **Door Size**: Change width/height values in `.door-frame` and `.door`
- **Animation Speed**: Modify the animation durations (default: 1.2s for doors, 0.8s for zoom)
- **Content**: Replace the welcome text and next page content in `index.html`

## 🎭 Animation Details

- **Door Opening**: 1.2 seconds with ease-in-out timing
- **Zoom Transition**: 0.8 seconds smooth scale animation
- **Platform Appearance**: Layered steps for visual depth
- **Text Pulse**: Gentle breathing animation on the "click" prompt

## 📱 Responsive

Works on all screen sizes from mobile phones to desktop displays.

Enjoy your Fun-Seum! 🎉
